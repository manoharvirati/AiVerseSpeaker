# AI English Coach

A Flutter mobile prototype for a premium, voice-first AI English speaking coach.

## Experience

- Home dashboard with daily goal, streak, quick practice, and AI recommendation.
- Full-screen speaking practice with tutor avatar, animated waveform, live transcript, and feedback card.
- Explore catalog for role play, interview, travel, pronunciation, IELTS, business English, and more.
- Progress dashboard with scores, weekly activity, weak areas, and recommended lessons.
- Profile view for tutor personas, AI memory, goals, and gamification.

## Run

```powershell
flutter pub get
flutter run
```
